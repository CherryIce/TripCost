## 国际化与无障碍检查

- `app_en.arb` 与 `app_zh.arb` 消息键集合、非空值和非开发键名由 `l10n_contract_test.dart` 校验。
- 设置页关键操作带按钮/开关语义；2.0 倍文字缩放下可滚动完成导出入口定位，由 `settings_page_test.dart` 校验。
- 金额使用 `MoneyFormatter` 和 Locale 数字符号；计算始终使用十进制模型，不解析展示字符串。
- CSV 使用稳定 ISO 时间/十进制字符串，避免表格 Locale 改变事实值；PDF 标题、字段和免责声明按 zh-Hans/en 生成。
- 横竖屏由 Runner 支持，设置页采用滚动布局；仍需模拟器分别复核浅/深色、横/竖屏和键盘遮挡。
- VoiceOver 朗读顺序、超大辅助功能字号、真机 Share Sheet、权限拒绝路径仍需真机记录，当前自动化不等同真机无障碍验收。
